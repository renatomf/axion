# Architecture Decision Records

One record per non-obvious decision: context, decision, consequences and the alternatives rejected.

- **Naming:** `NNNN-short-title.md`, numbered sequentially (e.g. `0002-modular-monolith.md`).
- **Immutability:** an accepted ADR is not rewritten. A changed decision gets a new ADR that supersedes the old one, and both are linked.
- **Template and process:** introduced in PR 0.04.
