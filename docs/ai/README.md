# AI

Governance documents for AI and ML features, following bank model risk practices (SR 11-7, NIST AI RMF).

- **Model inventory** (`model-inventory.md`): every model in use, its owner and risk tier.
- **Model cards** (`model-cards/`): purpose, data, limitations and monitoring per model.
- **Evaluation reports** (`evaluation-reports/`) and the **red-team report**.
- **AI risk assessment** (`ai-risk-assessment.md`).

First content arrives in phase 4.
