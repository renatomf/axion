# Design docs

One design doc per significant feature, written and approved before implementation starts.

- **Naming:** `YYYY-MM-DD-topic.md`, dated on creation.
- **Required sections:** problem, proposed solution, trade-offs and alternatives, and **Security considerations** with a STRIDE threat model.
- **Status:** each doc states `Draft`, `Approved` or `Superseded` in its header.
