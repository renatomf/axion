# Operations

How the system is run.

- **Runbooks:** step-by-step procedures for known operational tasks and alerts.
- **SLOs and metrics:** service level objectives and what is measured.
- **Incident procedures:** detection, response and communication.
- **Postmortems** (`postmortems/`): blameless write-ups of game days and incidents (timeline, impact, detection, recovery, root cause, follow-ups).
